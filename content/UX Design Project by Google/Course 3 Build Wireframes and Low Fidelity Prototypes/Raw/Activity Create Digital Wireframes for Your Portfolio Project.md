
* Convert hands-drawn wireframe into digital wireframe. 
* Use a grid to keep a consistent layout
	* You can use a layout grid in each frame to help you keep your margins and spacing consistent across your design. On the right side of the screen, there will be an option for the Layout Grid. Selecting the + button will add a new grid. The default layout grid is 10 px, but that can be changed by selecting the Grid icon. Spacing and margins will vary depending on the product you're working on. For now, use the following Layout Grid settings while working on your mobile app. Note: The settings need to be updated under both Grid and Columns. 
	* Grid parameters
		* **Size:** 10
		* **Color:** FF0000
		* **Count:** 12
		* **Type:** Stretch
		* **Margin:** 92
		* **Gutter:** 20
	* Build elements. Start with the elements that will be repeated across designs.

* Wireframe checklist
	* Do your digital wireframes:
	* Include at least three screens?
	* Demonstrate a complete user flow that a user can complete? 
	* Clearly define the UI elements intended for each screen, including navigation menus, buttons, visuals, and text fields?
	* Indicate the organization or hierarchy of any elements depicted on the screen?*
